# A5-25 Nightly 扩展测试结果

测试时间：2026-11-18 至 2026-11-19 18:01（Asia/Shanghai）。

## 1. 测试环境与方法

- 机器：a5-25，8 张 Ascend950DT。
- 容器：沿用 `inductor_a51112_pin_z00896543_20261116_195508`，未重新初始化环境。
- 权重：`/mnt/weight`。
- 运行模式：MRV2，默认 O2。
- 正确性：使用 8 组固定输入，比较同权重 eager 与 Inductor 的完整 token 序列、最终文本、分叉前 logprob 和 Top-K 候选重合情况；标准任务使用 MMLU、GSM8K，各 200 题。
- 性能：比较生产 default 与 Inductor，不使用 eager 作为性能基线。正确性与性能分开运行，性能数据来自独立服务测试。
- 性能负载：`vllm bench serve`，ShareGPT 的 QPS 1、4、16、inf；Qwen3.8-27B-w8a8 另测 8192/1024、32768/1024 长上下文负载。
- 每个性能配置重复 3 次，表中取中位数。吞吐单位为 output tokens/s；TTFT、TPOT 加速比大于 1 表示 Inductor 更快。
- 固定输入出现 token 或文本差异时，只要服务仍能正常生成，就不阻断独立性能测试。启动失败、超时和资源问题不作为有效性能数据。

**加粗规则：精度测试失败或阻塞项，以及加速比大于 1.05×或小于 0.95×的性能结果。**

## 2. 总体结果
